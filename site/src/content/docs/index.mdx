braccato-kotlin is a Kotlin port of [Braccato](https://github.com/better-lyrics/braccato), the synchronized
lyrics engine from [Better Lyrics](https://better-lyrics.boidu.dev). It reads lyrics files, times every
line and word against a player, and draws them with Compose Multiplatform, on the desktop JVM and on
Android.

It is a port rather than a binding: there is no WebView and no JavaScript runtime. The code follows
upstream file for file, so changes there can be carried over, and the views draw what upstream's
stylesheet draws, with its values.

## The modules

| Module | What it does |
|---|---|
| `braccato-types` | The lyric shapes: lines, timed parts, sync types |
| `braccato-parsers` | Reads lyrics files into those shapes |
| `braccato-core` | Builds lines, times them and decides what scrolls where, without a UI |
| `braccato-compose` | Draws them with Compose: the scrolling view and the stage |

Most apps need `braccato-compose` and `braccato-parsers`; the other two come along with them.
